Component Selection for Robotic Pets

IEEE ICRA 2023

▼

Authors

A. Kumar, et al.

Conference

IEEE ICRA

Year

2023

Topic

Component Selection

Fig 1: Electronic components for robotic pet assembly.

Objective

To provide a systematic framework for selecting the optimal components (sensors, motors, microcontrollers) for a robotic pet based on performance, cost, and availability.

Methodology

The authors evaluated 15 different components across 4 categories (motors, sensors, controllers, power). They used a weighted scoring system based on performance, price, power consumption, and availability.

Component Selection Criteria
CategoryCriteriaWeight
MotorsTorque, Speed, Price30%
SensorsAccuracy, Response Time, Cost25%
ControllersProcessing Power, I/O Pins, Price25%
PowerCapacity, Weight, Safety20%

Results

The framework identified the optimal component set for a robotic pet at $85 total cost. Arduino Nano + MG90S servos + HC-SR04 sensors were selected as best value for money.

Selected Components vs Alternatives
Arduino Nano (Selected)92% Score
Raspberry Pi (Alternative)78% Score
ESP32 (Alternative)85% Score

Conclusion & Relevance to RoboPet AI

This paper directly guides Gomes's role in RoboPet AI. Using this framework, we can select the best components that balance performance and cost, keeping our total budget under control.
