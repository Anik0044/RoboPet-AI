A Software Architecture for Social Robots

IEEE ICRA 2023

▼

Authors

M. H. et al.

Conference

IEEE ICRA

Year

2023

Topic

Software Architecture

Fig 1: Software architecture and code structure for social robots.

Objective

To propose a modular software architecture that makes it easier to develop, maintain, and upgrade social robot applications.

Methodology

The authors designed a layered architecture with clear interfaces. They separated the software into three main parts: Perception, Decision, and Action. They then implemented this architecture on a test robot.

Modular Software Architecture

PerceptionSense environmentCameras, Mic, Sensors
DecisionThink and planAI, LLM, Logic
ActionInteractMotors, Speaker

Results

The proposed architecture enabled rapid development and easy integration of new capabilities. It improved code reusability and reduced development time.

Development Efficiency Improvements
Code Reusability+70%
Reduction in Development Time-40%

Conclusion & Relevance to RoboPet AI

This paper directly guides the software architecture of RoboPet AI. By adopting this modular approach, our team can work on different parts of the software simultaneously without breaking the whole system.

The researchers conducted user studies with 60 participants from different age groups. They tested various UI designs (button-based, gesture-based, voice-based) and measured ease of use and error rates.

This paper provides the technical foundation for real-time data streaming in RoboPet AI. By using WebSocket, we can create a live dashboard showing our robot's sensor data in real-time.
